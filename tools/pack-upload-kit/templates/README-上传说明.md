# 游戏大厅增强 —— 创意工坊上传（你只需要双击一次）

> 这个文件夹是给**帮忙上传的朋友**用的。你不需要安装游戏、不需要装模组、不需要懂代码。

---

## 一、你要做的三步

1. **先把旧的那个上传文件夹整个删掉**（如果你之前跑过），再把压缩包**整个**解压到一个新文件夹，
   路径里最好不要有中文和空格（例如 `D:\upload`）。
   > 不要在旧文件夹上覆盖解压。资源管理器会逐项问「是否替换」，漏掉一次就会留下
   > 「新脚本 + 旧内容」的混合文件夹。这个包里的 `workspace\mod_id.txt` 已经带着工坊条目 ID，
   > 删掉旧文件夹不会丢任何东西。
2. 双击 **`upload.bat`**。
3. 等它跑完（一般一两分钟），把文件夹里新出现的 **`上传结果.txt`** 发回给作者。

就这样。脚本不会问你任何问题，不需要做任何选择。

---

## 二、三条前提（脚本会自己检查并说明）

| # | 要求 | 不满足时 |
|---|---|---|
| 1 | Steam 账号**拥有**《杀戮尖塔 2》（AppID 2868840） | 报 `k_EResultAccessDenied`，提示换账号 |
| 2 | Steam 客户端开着并已登录（不能是离线模式） | 提示先登录 |
| 3 | 第一次上传可能要接受一次 Steam 创意工坊法律协议 | 打出网址，照着点一下，再双击一次即可 |

> 家庭共享借来的游戏**不算**拥有，会被 Steam 拒绝。

---

## 三、这个文件夹请完整保留

脚本会把工坊条目的数字 ID 写进 `workspace\mod_id.txt`。
那是**以后更新同一条目的唯一凭据**，丢了就只能新建第二个条目。

所以：

- 不要删、不要移动、不要改名这个文件夹；
- 不要只把里面某几个文件拷到别处再运行；
- 上传成功后也请留着，作者可能还要请你更新一次。

---

## 四、出错了怎么办

脚本不会一闪而过。任何一步失败，它都会在窗口里直接写出：

- **原因**（翻译成人话，不是错误码）；
- **怎么办**（一二三条具体动作）。

同样的内容会写进 `上传结果.txt`。**你不需要判断，把这个文件发回给作者就行。**

窗口最后会停住等你按回车，方便截图。

## 五、包里有什么

```
sts2-lobby-enhance-upload-kit/
  upload.bat             <- 双击这个
  upload.ps1             <- 脚本本体（upload.bat 会调用）
  README-上传说明.md      <- 本文件
  CHECKSUMS.txt          <- 文件哈希，脚本自检用
  ModUploader/           <- MegaCrit 官方上传器 v0.2.0
    ModUploader.exe
    steam_api64.dll
    steam_appid.txt
  workspace/             <- 真正上传的内容
    workshop.json        <- 标题 / 简介 / 可见性(public) / 必需物品
    image.png            <- 封面（512×512）
    content/             <- 原样传到工坊
      sts2_lobby_enhance.dll
      sts2_lobby_enhance.json
      LICENSE
      THIRD_PARTY_NOTICES
```

上传成功后还会多出：`ModUploader\mod-uploader.log`、`上传结果.txt`。

`workspace\mod_id.txt` **包里本来就带着**（内容是工坊条目的数字 ID）。它是"更新同一个条目"的凭据，
删掉它下次上传就会新建第二个条目 —— 所以整个文件夹别删别挪。

## 六、这个模组是什么

《杀戮尖塔 2》0.113 的**联机大厅增强**：让社区模组 LAN Connect（`sts2_lan_connect` 0.6.3）继续可用，
并补上极速 / 恐惧模式联机、局中重开、结算页一键新开一局等功能。
它**不包含**社区模组的任何文件，只在 `workshop.json` 里声明依赖（工坊物品 3749766330）。

版本：**{VERSION}**（以 `workspace/content/sts2_lobby_enhance.json` 里的 `version` 为准）
